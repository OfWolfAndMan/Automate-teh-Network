# Pinned. The corpus this repository replaces targeted Ansible 2.3 on Python 2.7;
# every module it called left ansible-core in the 2.10 collection split.
#
# 2.21.6 is the newest version published to PyPI at the time of writing. A pin to a version
# that does not exist on the index the runner uses is not a pin, it is an outage: CI proved
# it by failing `pip install` in every job while the local uv environment resolved 2.22.0
# from a cache this repository cannot see.
ansible-core==2.21.6
